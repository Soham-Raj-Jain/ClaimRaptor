# ClaimRaptor Submission Review

This branch is the final hackathon review surface for ClaimRaptor.

## What judges should review

- NDI-based insurance PDF parsing
- Drex vs Qwen live head-to-head comparison
- Frozen 30-case Apex Predator benchmark
- Accuracy, latency, consistency, and cost methodology
- Real-world public-document evaluation
- Intern-assisted reliability hardening
- README, presentation, and submission assets

## Key benchmark result

Drex Max v1.1 achieved:
- 100% accuracy vs 96.67% for Qwen3.8-27B
- 225 ms vs 283 ms median latency
- 324 ms vs 1239 ms p95 latency
- 100% vs 96.67% consistency
- approximately 5.19x lower inference cost

The public real-world document test is intentionally reported separately and is not presented as an accuracy benchmark.
